# 界面介绍

## 1. 主界面布局

### 1.1 整体结构

```
┌─────────────────────────────────────────────────────────┐
│  [≡] New Chat                              [⚙] [☰]    │
├─────────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌────────────────────────────────────┐  │
│  │ 历史记录  │  │                                    │  │
│  │          │  │                                    │  │
│  │ • 会话1   │  │        对话区域                     │  │
│  │ • 会话2   │  │                                    │  │
│  │ • 会话3   │  │                                    │  │
│  │          │  │                                    │  │
│  └──────────┘  └────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│  [请输入您的问题...]                              [发送] │
└─────────────────────────────────────────────────────────┘
```

### 1.2 界面组件

| 组件 | 说明 |
|------|------|
| 侧边栏 | 左侧区域，包含新建聊天和历史记录列表 |
| 主内容区 | 右侧区域，显示对话内容和交互控件 |
| 输入框 | 底部区域，用于输入问题 |
| 配置按钮 | 右上角，用于打开配置面板 |

---

## 2. 侧边栏

### 2.1 新建聊天

- **位置**：侧边栏顶部
- **功能**：点击创建新的对话会话
- **快捷键**：`Ctrl/Cmd + N`

### 2.2 历史记录列表

- **位置**：侧边栏中部
- **功能**：显示所有历史对话会话
- **操作**：
  - 点击切换会话
  - 右键打开上下文菜单（重命名、删除）

---

## 3. 配置面板

### 3.1 打开配置面板

- **方式**：点击右上角配置按钮（⚙）
- **快捷键**：`Ctrl/Cmd + ,`

### 3.2 配置面板内容

#### AI 模型配置

| 配置项 | 说明 |
|--------|------|
| Model Engine | 选择模型引擎（Ollama、DeepSeek 等） |
| API URL | API 地址（留空使用默认端点） |
| API Key | API 密钥 |

#### 高级选项

| 配置项 | 说明 |
|--------|------|
| Context Compression | 上下文压缩（移除历史中的思考过程以节省 tokens） |

#### CLI 与 SSH 连接

| 配置项 | 说明 |
|--------|------|
| Enable Remote Execution (SSH) | 启用远程服务器执行 |
| CLI Prompt File | CLI 提示词文件路径 |
| SSH Host | SSH 主机地址 |
| SSH Port | SSH 端口（默认 22） |
| SSH Username | SSH 用户名 |
| SSH Password | SSH 密码 |

#### MCP 服务

| 配置项 | 说明 |
|--------|------|
| Disable BioTools | 禁用 BioTools 服务 |
| MCP Server URL | MCP 服务器地址 |
| MCP Server Token | MCP 服务器令牌 |

---

## 4. 对话区域

### 4.1 消息显示

- **AI 消息**：左侧显示，带有 AI 图标
- **用户消息**：右侧显示，带有用户图标

### 4.2 交互控件

每条 AI 消息下方提供以下交互控件：

| 控件 | 功能 |
|------|------|
| 👍 点赞 | 反馈结果质量 |
| ❌ 删除 | 移除冗余或错误输出 |
| 📍 定位 | 跳转到对应 JSON 内容 |
| 🪶 引用 | 提取段落用于后续分析 |

### 4.3 思考过程

- 显示 AI 的思考过程
- 可折叠/展开查看详情

---

## 5. 模式切换

### 5.1 代理模式

通过侧边栏或配置面板切换：

| 模式 | 说明 |
|------|------|
| TransAgent | 转录调控领域任务分析（默认） |
| MultiAgent | 多智能体协作模式 |
| BaseAgent | 基础模式 |

### 5.2 行为模式

| 模式 | 说明 |
|------|------|
| AUTO | 自动模式（全流程自动执行） |
| ACT | 执行模式（允许交互与反馈） |
| PLAN | 规划模式（生成完整计划后再执行） |
| FLASH | 快速响应模式 |

---

## 6. 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + N` | 新建聊天 |
| `Ctrl/Cmd + ,` | 打开配置面板 |
| `Ctrl/Cmd + Enter` | 发送消息 |
| `Ctrl/Cmd + L` | 清除当前对话 |
